## Part C — Key-principle callouts (page-anchored)

1. **Stable growth ≤ risk-free rate / economy growth** — Ch.12, PDF 325–326 (printed 306–307). Terminal g cannot exceed nominal GDP ≈ the risk-free rate; else the firm outgrows the economy. *Guardrail.*
2. **Implied (forward) ERP** — Ch.7, PDF ~192 (printed ~173). Back-solve r from index level = Σ CF/(1+r)^t; ERP = r − rf. Preferred over pure historical ERP.
3. **Bottom-up beta** — Ch.8, PDF 216–218. `β_unlevered = β_comp /[1+(1−t)(D/E)_comp]`, then relever to firm D/E. Use for private/pre-revenue/recent-IPO firms.
4. **WACC needs market-value weights** — Ch.8, PDF 239. `ke·E/(D+E+PS) + kd(1−t)·D/(…) + kps·PS/(…)`. Never book weights.
5. **Fundamental growth = Reinvestment Rate × ROC** — Ch.11, PDF 311–314. Growth creates value only if **ROC > WACC**.
6. **Options/dilution — value as a liability** — Ch.16, PDF 462–466 (also p.371 Ch.14, p.658 Ch.23). Don't ignore; don't use fully-diluted shortcut (drops time premium). Value ESOs via dilution-adjusted Black-Scholes, subtract from equity, divide by **basic** shares. **For future fair-value raises (young/biotech): dilution is already in the negative cash flows — re-charging is double counting (p.371/p.443/p.658).** See `damodaran_dilution_sharecount_principles.md`.
7. **Patent / R&D as a real option (biotech rNPV)** — Ch.28, PDF 800–806. S = PV(commercialize now), K = development cost, σ² = project-value variance, **cost of delay ≈ 1/(patent life)** acts like a dividend yield.
8. **EVA = DCF, rearranged** — Ch.32, PDF 889–891. `EVA=(ROC−WACC)·Capital`; `Firm value = Capital + PV(EVA in place) + PV(EVA future)`. Value needs a sustained ROC−WACC spread, not just earnings growth.
